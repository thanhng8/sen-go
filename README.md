# SEN · GO

[English](README.md) · [Tiếng Việt](README.vi.md)

A top-down 2D Go game built with HTML, Three.js, and JavaScript. Play against the built-in local computer or an online AI model through an API gateway.

## Overview

**SEN · GO** is a browser-based Go game rendered with Three.js. You can play entirely locally against the built-in algorithm or use an online AI model through an API. The local engine remains authoritative for move legality, rule enforcement, and scoring.

## Features

- Three board sizes: **9×9**, **13×13**, and **19×19**.
- Play as Black or White.
- Two opponent modes:
  - **Local computer:** no network or API key required, with Easy, Medium, and Hard levels.
  - **AI via API:** use a model name entered by the player.
- Six supported AI gateways: OpenAI, Claude, Grok, Gemini, OpenRouter, and Ollama Cloud.
- Three rule sets:
  - Japanese rules — territory scoring, 6.5 Komi.
  - Chinese rules — area scoring, 7.5 Komi.
  - New Zealand rules — area scoring, 7.0 Komi, and suicide allowed.
- Local validation for captures, suicide, simple Ko, and positional superko.
- Undo, pass, resign, and score actions.
- Four interface themes, four board surfaces, and four stone sets.
- Configurable font, **16–26px** text size, and text color.
- Preferences persisted in `localStorage`.
- 15 display languages: Vietnamese, English, Simplified Chinese, Japanese, Korean, Spanish, French, German, Portuguese, Russian, Arabic, Hindi, Indonesian, Thai, and Turkish.
- RTL layout support for Arabic.
- Responsive desktop and mobile layout.

## Requirements

- Node.js and npm.
- A modern browser with ES module and WebGL support.
- Local computer mode does not require an Internet connection after installation.
- API mode requires Internet access, a valid API key, and available quota from the selected gateway.

## Installation

```bash
git clone https://github.com/thanhng8/sen-go.git
cd sen-go
npm install
npm run dev
```

Open the URL printed by Vite, usually:

```text
http://localhost:5173
```

Do not open `index.html` directly with `file://`, because the project uses ES modules.

## Playing against the local computer

1. Select a board size.
2. Select **Local computer** under **Opponent**.
3. Choose Black or White.
4. Select Easy, Medium, or Hard.
5. Choose a rule set.
6. Select **Start match**.

Move selection and rule validation run entirely in the browser. No game data is sent to an external service in this mode.

## Configuring and playing against an API AI

### 1. Configure the AI

Open **Settings**, then find **AI via API**:

1. Select a gateway.
2. Enter the exact model name. The model field is free-form and is not restricted to a predefined list.
3. Enter the API key for the selected gateway.
4. Close Settings. The provider, API key, and model name are saved automatically in this browser.

Common model-name formats include:

| Gateway | Example model format |
|---|---|
| OpenAI | `gpt-...` |
| Claude | `claude-...` |
| Grok | `grok-...` |
| Gemini | `gemini-...` |
| OpenRouter | `provider/model-name` |
| Ollama Cloud | `model-name:cloud` |

Available model names depend on your account and may change. Copy the exact identifier from the gateway dashboard or documentation.

### 2. Start an AI match

1. Return to the match setup screen.
2. Select **AI via API** under **Opponent**.
3. Confirm the gateway and model displayed below the option.
4. Select the board, your color, and the rule set.
5. Select **Start match**.

If the API key or model name is missing, the game opens Settings and asks you to complete the configuration first.

### 3. How an AI turn works

For every AI turn, the game sends:

- The game name and board size.
- The AI stone color.
- The selected rules, scoring method, Komi, Ko rule, and suicide setting.
- The current board position.
- Captures, consecutive passes, and recent actions.
- A list of legal actions generated by the local engine.

The AI must choose one legal move or pass. `go-engine.js` validates the response again before applying it. If the gateway fails, times out, or returns an illegal action, the local computer plays that turn so the match does not become stuck.

## API key notice

The API key and model name are stored in `localStorage` under:

```text
sen-go.preferences.v1
```

This is intended for personal computers. Please note:

- `localStorage` data is not encrypted.
- Do not use a sensitive API key on a shared computer.
- Never hard-code an API key in the source or commit it to GitHub.
- Use **Restore defaults** in Settings or clear the browser site data to remove the saved key.
- Each AI turn may create one billable API request.
- Some gateways or browser environments may reject direct requests because of CORS restrictions.

## AI troubleshooting

- **401/403:** the API key is invalid, expired, or not authorized for the model.
- **429:** the account has reached its quota or the gateway is rate-limiting requests.
- **Model not found:** verify the exact model identifier and any required provider prefix.
- **Timeout:** try a faster model or check the network connection.
- **CORS/network error:** the gateway may not allow direct browser requests. Use another gateway or add a local proxy.
- **Illegal AI move:** the local engine rejects it and uses the local computer for that turn.

## Current limitations

- General-purpose language models are not dedicated Go engines, so playing strength depends on the selected model.
- The game does not automatically identify dead groups during final scoring. Capture dead groups before scoring.
- Online AI mode depends on gateway availability, quota, and CORS policy.
